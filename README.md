Translating GPig algorithm from MATLAB to Python. Original GitHub can be found at https://github.com/alisonpchase/Rrs_inversion_pigments.

Paper where method was used:

Chase, A., E. Boss, I. Cetinic, and W. Slade. 2017. "Estimation of Phytoplankton
        Accessory Pigments from Hyperspectral Reflectance Spectra: Toward a
        Global Algorithm."
        Journal of Geophysical Research: Oceans, doi: 10.1002/2017JC012859.

Coefficients have been re-tuned on a 162 sample dataset as opposed to the 97 sample dataset used in the original paper (Chase et al. 2017).
